# ✨ FAHIM BOT

> A powerful and customizable Facebook Messenger Bot built with Node.js.

## 🚀 Features

- 🤖 AI Chat
- 🎵 Music Downloader
- 📹 Video Downloader
- 🖼️ Image Editor
- 👥 Group Management
- 💰 Economy System
- 🎮 Mini Games
- ⚙️ Custom Commands

## 📦 Deploy

```bash
npm install
npm start
```
